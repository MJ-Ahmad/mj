# 22. Development Workflow

All activities must follow the standardized lifecycle:

```text
pc → ep → ud → ur → bv → fv → cr
```

### Workflow Meaning

| Code | Description |
|--------|--------|
| pc | Preliminary Collection |
| ep | Experimental Phase |
| ud | Under Development |
| ur | Under Review |
| bv | Beta Version |
| fv | Final Production Version |
| cr | Currently Running |
