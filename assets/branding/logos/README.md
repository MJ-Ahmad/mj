## ⚙️ Usage Notes
- সব `.svg` ফাইল মূল ডিজাইন সোর্স হিসেবে ব্যবহৃত হবে।
- `.png` ফাইলগুলো ওয়েব, অ্যাপ ও সোশ্যাল মিডিয়ায় সরাসরি ব্যবহারযোগ্য।
- `.ai` এবং `.fig` ফাইলগুলো ডিজাইন টুল (Adobe Illustrator, Figma) এ এডিট করার জন্য।
- স্ক্রিপ্টসমূহ `~/scripts/` ডিরেক্টরিতে সংরক্ষিত আছে এবং প্রতিটি সাবডিরেক্টরির জন্য আলাদা জেনারেটর স্ক্রিপ্ট তৈরি করা হয়েছে।
